# Ariadne v1.0 research notes — 2026-09-30

This document records the primary-source research used for the v1.0 Last.fm integration and analytics/UI pass.

## Last.fm exact username lookup

Primary sources:

- Last.fm `user.getInfo`: https://www.last.fm/api/show/user.getInfo
- Last.fm REST request format: https://www.last.fm/api/rest
- Last.fm API introduction / usage guidance: https://www.last.fm/api/intro
- Last.fm authentication overview: https://www.last.fm/api/authentication

Observed/documented contract used by Ariadne:

- `user.getInfo` accepts a `user` parameter and requires an API key.
- The method does not require user authentication.
- A successful response returns a canonical `user.name`, which Ariadne compares case-insensitively with the requested username.
- Last.fm documents structured API errors and messages.
- Ariadne treats an explicit API response whose message says `User not found` as an exact miss.
- Invalid/suspended keys and rate-limit errors become Blocked.
- Other API errors, missing names, or mismatched names stay Couldn’t tell.

Ariadne does not use the Last.fm account secret because this read-only lookup does not require authenticated-user access.

## Analytics semantics

The new analytics are derived from the current in-browser scan report. No persistent product telemetry was added.

The product intentionally avoids synthetic identity, privacy, reputation, or safety scores. The metrics describe source coverage, evidence resolution, uncertainty, and observed source response time only.

Definitions are maintained in `docs/product-metrics.md`.

## UI/accessibility references

Primary accessibility references:

- WCAG 2.2 Understanding 1.4.1, Use of Color: https://www.w3.org/WAI/WCAG22/Understanding/use-of-color
- WCAG 2.2 Understanding 2.4.7, Focus Visible: https://www.w3.org/WAI/WCAG22/Understanding/focus-visible
- WCAG 2.2 Understanding 2.5.8, Target Size (Minimum): https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum

Implementation decisions:

- chart values and labels are printed in text; color is supplemental;
- interactive controls retain explicit visible focus treatment;
- filter/action targets use minimum heights and spacing rather than tiny adjacent controls;
- charts are native HTML/CSS rather than a new runtime dependency, keeping the bundle and attack surface smaller.
